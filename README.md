# How Spider Traits Differ Across the World

## Description
This repo contains all files for completing the cross dataset ingestion and visualization project as was a requirement for EDS 213: Databases and Data Management as part of the Masters of Environmental Data Science program with the Bren School of Environmental Science and Mangement at UCSB.

The goal of this project was to cross reference the traits of spider species by WWF biome standardization, to determine the average traits across each biome.
